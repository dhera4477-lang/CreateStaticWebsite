AI-Powered Static Website Generator   
A modern web application built with TypeScript, React, and Vite that allows users to create static websites using AI.   

🚀 Features   
AI-Driven Website Generation: Create clean and modern web layouts effortlessly.   

TypeScript Support: Fully typed codebase for reliability and scalability.   

Fast Development & Build: Powered by Vite and pnpm for lightning-fast build times.   

Figma Integration: Built from Figma Make templates for seamless UI/UX design.   

🛠️ Tech Stack   
Frontend: React, TypeScript, HTML5, CSS3   

Build Tool: Vite   

Package Manager: pnpm   

💻 Getting Started   
Follow these instructions to get a copy of the project up and running on your local machine.   

Prerequisites   
Make sure you have Node.js and pnpm installed on your system.   

Bash
npm install -g pnpm
Installation & Setup
Clone the repository:

 Bash
  git clone https://github.com/dhera4477-lang/CreateStaticWebsite.git
  cd CreateStaticWebsite
Install dependencies:

Bash
pnpm install
Start the development server:

Bash
pnpm run dev
📦 Build for Production
To create a production build of the application:

Bash
pnpm run build
